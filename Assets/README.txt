========================================
倶楽部蟹戦 -CRAB FIGHT CLUB-
========================================

カニたちが「地上最強の蟹」の座を懸けて争う、
読み合い × 連打の対戦ゲームです。


----------------------------------------
■ 概要
----------------------------------------

一蟹（いちかに）から九蟹（きゅうかに）までの9枚の牌を
1枚ずつ出し合い、勝ったラウンド数を競います。

数字が大きいほど強い……とは限りません。
差が小さい勝負は「連打バトル」に突入し、
数字で負けていても連打で押し切れば逆転できます。

先に5ラウンド先取したカニが、勝ちです。


----------------------------------------
■ 遊び方
----------------------------------------

【1】 手札を選ぶ
　　 一蟹～九蟹の9枚から1枚を出します。
　　 牌は使い切りで、同じ数字は二度使えません。
　　 相手の残り手札は常に見えています。

【2】 数字で勝負がつく……とは限らない
　　 ・数字の差が3以上 → 大きい方がそのまま勝ち
　　 ・数字の差が2以内 → 連打バトルに突入！

【3】 連打で押し切れ
　　 10秒間、2つのキーを交互に連打します。
　　 数字で負けていても、連打で押し勝てば逆転勝ち。
　　 ただし数字が有利な側ほど守りが堅く、
　　 不利な側はより多く連打しなければ勝てません。

【4】 下克上
　　 最強の九蟹は、最弱の一蟹に弱い。
　　 大きい牌を出すときは、足をすくわれる覚悟を。
　　 （下克上マッチ：一蟹 vs 九蟹 / 一蟹 vs 八蟹 / 二蟹 vs 九蟹）


----------------------------------------
■ 操作方法
----------------------------------------

【選択フェーズ】
　1～9キー　　　… 牌を直接選択
　←→キー　　　 … カーソル移動
　Enterキー　　 … 決定
　Escキー　　　 … ポーズ（選択フェーズ中のみ）

【連打フェーズ】
　1P … AキーとDキーを交互に連打
　2P … ←キーと→キーを交互に連打（ふたりでモード）
　※ 同じキーを連続で押しても加算されません

【試合終了後】
　Rキー　　… もう一度対戦
　Escキー　… タイトルへ戻る


----------------------------------------
■ モード
----------------------------------------

【ひとりで】
　CPUと対戦します。難易度は3段階（+隠し1段階）。

　・サワガニ級　　（カニレベル・低）
　・毛ガニ級　　　（カニレベル・中）
　・タラバガニ級　（カニレベル・高）

　CPUは残り手札から最適な出し方を計算して手を選びます。
　また、連打を重ねるほどCPUも疲労し、連打速度が落ちていきます。

【ふたりで】
　1台のPCで2人対戦します。
　手札を選ぶ番ではない人は、画面から目を離してください。
